# Kalbur Saman

Programlamaya Giriş dersi vize projesi için hazırlanan masal derlemesi web sayfası.

## Öğrenci Bilgileri

- Ad Soyad: Fatmanur Konya
- Öğrenci Numarası: 86250017
- Üniversite: İstanbul Medipol Üniversitesi
- Bölüm: Görsel İletişim Tasarımı
- Sınıf: 2. sınıf
- Ders: Programlamaya Giriş

## Projenin Amacı

Sekiz masalın kısa uyarlamasını, kullanıcıların kolayca bulabileceği ve okuyabileceği bir web sayfasında bir araya getirmek.

## Özellikler

- Sekiz masal kartı
- Masal adına göre arama
- Kategoriye göre filtreleme
- Masalları okuma penceresinde açma
- Okuma yazısını büyütme ve küçültme
- Telefon ekranına uyum sağlayan tasarım
- Pastel pembe, açık mavi ve lila renkler

## Kullanılan Teknolojiler

HTML, içsel CSS ve içsel JavaScript kullanılmıştır. Stil ve JavaScript kodları tek HTML dosyasının içinde bulunmaktadır.

## Nasıl Açılır?

1. Depodaki `online_viewer_net-7.html` dosyasını indirin.
2. İndirilen dosyayı bir web tarayıcısıyla açın.
3. Arama veya kategori seçimiyle bir masal bulun.
4. “Masal oku” düğmesine basarak metni açın.
